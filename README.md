# Coming-Soon-Landing-Page

A modern and responsive **Coming Soon Landing Page** built using **HTML5** and **CSS3**. The page features a clean UI with a purple-blue gradient background, a centered glass-style card, a shield logo, an SVG wave design, and a call-to-action email notification form.

🔗 **Live Demo:** https://tusharrjdash.github.io/Coming-Soon-Landing-Page/
